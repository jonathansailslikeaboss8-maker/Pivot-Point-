# Pivot-Point Ship simulator
Pivot Point is a ship simulator for android devices. It gives maritime enthusiast everything they ever wanted in a complex and advanced sandbox experience.

# Missions
- Berthing and Unberthing missions
- Shifting missions
- Check rides and type ratings for different ship types and propulsion systems
- Towing and ship assist 

# Features 
- Send your mooring lines ashore
- Anchoring
- Free roam
- Full control of ships systems
- Raise and lower ramps on supported ships
- See propulsion through the deck  

 # Propulsion types 
 - Twin screw
 - Single screw
 - CPP
 - Voith Schneider
 - Azimuth
 - Water jets
